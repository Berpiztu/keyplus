# windows/ — Berpiztu AI Keyboard for Windows

## Purpose

- A Windows app (.NET 10, WPF, `net10.0-windows10.0.19041.0`) with the standard keyboards, Standard and Standard PC, and those designed from them, in a floating card that never takes the focus from the window typed in, its keys sent to that window

## Ownership

- This file owns `windows/`; the layouts, the design format, the keyboards' record and the keys' signs it uses belong to the root (`StandardKeys.cs`, `StandardDesign.cs`, `KeyboardEntry.cs`, `Resources/drawable/`)
