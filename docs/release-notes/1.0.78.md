## The log, on Android and Windows

- **Warnings and errors marked**: a warning's line says WARN, an error's
  says ERROR with the error whole and where it happened. Failures that left
  no trace are now written too.
- **In colour**: Troubleshooting's log shows errors in red and warnings in
  yellow.
- **A slow keyboard is written**: when the keyboard takes 200 ms or more to
  answer, the log says for how long and what it was doing, never the text.
- **An error that closes the keyboard** is written on Android too, as it was
  on Windows.

## Fixes

- **Windows**: the keyboard no longer closes when a space ends a word with
  the context model on and the sentence lost (a click in the text, the
  computer's keys).
- **Android**: Troubleshooting's log scrolls inside its box, not the page.
