## Import and export your keyboards on Windows

Theme now has Import designs and Export designs under the keyboard drawn. Export
writes every keyboard you saved, with its language and designs, to a file. Import
adds a file's keyboards to the list: nothing is replaced, and one already there
is not added twice.

## The keyboard window keeps its size on Windows

Its edges only resize it while the Resize tool is on, and it can no longer be
maximized by accident.

## An icon stays an icon on Windows

Once the keyboard has become its icon, going to a text field no longer brings it
back: click the icon, or choose Restore keyboard in the menu of its icon by the
clock. With the keyboard in sight, that menu says Make icon.
