Agreed: not a Gboard clone; its ideas, so they are not thought out again.
A setting is made where the code would otherwise fix a value (the long
press's duration, the key popup, sound, vibration…), in the page Gboard
has it in; Gboard's other options are not made. Diseñar stays where it is
now (⚙ in the keyboard) for the time being.
