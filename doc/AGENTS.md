# doc

## Purpose

- Design notes behind KeyPlus's layout decisions, and the owner's reference captures they come from

## Ownership

- The owner writes the requests, notes and sketches; agents add analysis and plans when asked
- Product, build and release rules stay with the root AGENTS.md

## Local Contracts

- `diseño.md`: key labels, the three-by-three legend table, analysis and plan, followed by the owner's notes in Spanish
- `compact-keys.md`: Keys in two rows as Termux lays them out, the owner's request of 17 October 2026, the drawings and the details to confirm
- `dise.md`: the owner's raw sketch of the legend grid
- `Screenshot 2026-10-16 232102.png`: a 75% hardware keyboard, the reference for the Home, PgUp, PgDn and End column at the right
- `clicbo/`: phone captures (photos, videos) of Gboard's clipboard (Portapapeles) beside KeyPlus, the reference for the copied-things UI; `clicbo/New folder/` holds more of the same
- `clicbo/wslc-ai-agent.code-workspace`: a VS Code workspace opening wslc-ai-agent and keyplus together, not documentation

## Work Guidance

- The owner's notes and drawings stay as written; a reading of them goes beside them, marked to confirm, as `compact-keys.md` does
- A capture that shows personal data (chats, bank details, accounts) is never committed: it is kept in `private/clicbo/`, which git ignores; look at a capture before adding it
